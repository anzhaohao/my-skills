这个 skill 用于在新建项目、部署服务、开发较大功能、引入工具或替换工作流前，先查找可复用资源，减少重复造轮子。

# 什么时候触发

- 准备从零搭建软件、服务、自动化或开发框架。
- 需要引入新工具、替换现有工具或部署第三方项目。
- 预计会进行多文件、长时间或有部署风险的实现工作。

# 核心流程

1. 第一轮只读扫描本地项目、Skills、脚本、模板和部署清单。
2. 使用 `agent-reach` 检索官方仓库、文档、发行版、包仓库和 Docker 候选。
3. 比较需求匹配、部署难度、维护、许可证、安全、兼容性和改造成本。
4. 输出推荐方案、淘汰理由、实施命令、风险和回滚方式。
5. 停止并等待明确的二次确认，确认后才克隆、安装、编辑或部署。

# 当前边界

默认不遍历整盘、私人笔记库、大型数据集、缓存和依赖目录；默认不读取密钥、Cookie、令牌或私钥。用户明确要求立即实施时，可以记录例外并跳过调研门禁。
