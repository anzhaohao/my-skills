## 3. 原理示意（blob / 双面板）

**A. 对比式（左 N 个 → 右 1 个）**
```
三个 blob (rx74, ry54, 角度 -18/-2/+15)  cx=150/322/494, cy=300
箭头 (596,300)→(668,300)
一个大的虚线 blob (rx218, ry104) cx=900
底下灰条 1176×52 @ (60, 516)
```
**B. 坐标轴式（散点 + 阈值线）**
```
轴：(112,470)→(112,196) 与 (112,470)→(628,470)，2.2px
均值虚线 y=330；±σ 浅红虚线 y=288 / 372，dash "5 6"
散点 12 个 r=6.5，x 从 150 每 41 一个，y 在 ±35 内跳
σ 双箭头：x=612，y 288→372，中间标 στ
```
**C. 时域对比**
```
两条 gauss：单发 sigma=34 红；平均 sigma=92 灰虚线 "9 7"；同基线 y=470
```
