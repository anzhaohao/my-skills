# 安钊锋的组会 PPT 风格规范（实测版）

数据来源：`00_组会\20260824\组会-安钊锋.pptx`（17 页原稿）的 OOXML 尺寸、颜色、字号实测值，
加上 2026-10-30 FROG-CNN 汇报这一轮迭代后双方确认的调整。凡是"原稿"与"现在"不一致的地方都标了出来。

---

## 1. 一句话概括

**一页一张图，标题写结论，底部一条米黄结论条；其余文字都是图的注脚。**
不追求信息密度，追求"听众一眼看懂 + 你自己能顺着图讲下来"。

---

## 2. 画布与坐标

| 项 | 值 |
|---|---|
| 画布 | 16:9，13.333 × 7.5 in = 12192000 × 6858000 EMU |

## 3. 页面骨架（三条横带，互不重叠）

```
y  8 ───────────────  标题带（页面标题基线 y=60）
y 92 ───────────────  主图带（有结论条时到 620；整页图可到 690）
y 648 ─ 712          结论条（高 64，左右各留 42–44）
```

- 左边距：标题 `x=20`，正文 `x=40–60`；右边距 `40`，安全右界 `1240`。
- 主图必须占版面的 **≥60%**（结果页通常 80–95%）。
- 三个带之间不要塞东西；宁可留白。

---

## 4. 标题

**写法（最重要）**：`主题——说明`，中间是两个全角破折号。

```
研究背景——超快光场当前的表征方法
方案架构——CNN 直读，50 毫秒
结果 II——抗噪：加性 92%，乘性 95%
评价——它能做什么、不能做什么
```

- 主题 2–4 字（研究背景 / 方案架构 / 实验方案 / 关键设计 / 结果 I–III / 评价 / 个人思考 / 总结）。
- 说明是一句**结论或范围**，不是"结果一""方法"这种空标签。
- 整行 ≤ 26 个全角字（44 px 时约 1150 px 宽）。

| 项 | 原稿 | 现在 |
|---|---|---|
| 字号 | 32 pt = 42.7 px | **44 px** |
| 颜色 | `#767171`（深暖灰） | 同 |
| 位置 | x=18.4, y=18.7 文本框，基线≈56 | x=20，基线 **60** |

**例外（照原稿）**：
- 封面没有页面标题。
- "这篇论文讲的什么东西？"页没有页面标题——那句问句本身是正文，38 px 灰 `#7A7A7A`，放在右栏。
- 过渡页（大问句）也没有标题，只有一行 36–46 px 的字，关键词上色。

## 5. 配色（只按角色用，不按喜好用）

| 角色 | 色值 | 用在哪 |
|---|---|---|
| 标题灰 | `#767171` | 页面标题 |
| 正文黑 | `#111111` | 所有正文、要点 |
| 关键词蓝 | `#4472C4` | 术语、机构、变量名（FROG、CNN、ICN） |
| 关键词红 | `#E23B2E`（原稿 `#FF0000`） | 痛点、结论、边界、错误 |
| 结构深蓝 | `#2F5597` | 编号、坐标轴标注、小栏目标签 |
| 深藏青 | `#1F3864` | 编号方块底、强调标题 |
| 结论条米黄 | `#FFF7EE` | 底部结论条底（原稿另有 `#E9DABB` 描边，已去掉） |
| 浅蓝块 | `#F3F6FB` / `#E7EEF9` | 输入块、特征图块 |
| 浅红块 | `#FBE7E4` | 对照列、测试集、回归头 |

**禁用**：渐变、阴影、发光、描边卡片（"我喜欢无边框"）、彩色底纹大面积铺。

## 7. 结论条（页面的"落点"）

- 圆角矩形：`x=44, y=648, w=1192, h=64, rx=8`，填充 `#FFF7EE`，**无描边**。
- 文字 30 px、居中、加粗，**关键词上色**（红=结论/痛点，蓝=术语）。
- 一句话，≤ 34 个全角字；写成"判断句"而不是"说明句"：

```
把“先重建脉冲、再评估稳定性”变成一次读数。
实时性把不稳定性测量从“事后分析”变成“在线诊断”。
```

- 结果页如果已经用大数字表达了结论，**可以不要结论条**（避免重复）。

## 8. 图（这一页的主角）

### 8.1 优先级
1. **论文原图**（Fig.1–4）：不重绘、不裁掉坐标轴/图例/色条，按原比例 `meet` 放。
2. **自绘示意图**（SVG）：物理过程、流程、架构、数据结构。
3. **淡化截图**：论文首页/摘要，做背景氛围。
4. 纯文字卡片：只在没有更好表达时用，且每页 ≤3 条。

### 8.2 论文原图的尺寸
| 比例 | 宽度 | 高度 | 典型位置 |
|---|---|---|---|
| 2.8:1（如分类混淆图） | 1180 | 420 | y=100，下方放大数字 |
| 1.87:1（FROG 轨迹） | 1080 | 575 | 整页，y=96 |
| 1.87:1 + 右栏 | 940 | 503 | 右栏放 2 个大数字 |
| 1.45:1（回归散点） | 760 | 525 | 右栏放 7.1% + 3 行 |

### 8.3 淡化截图（封面 / 论文首页）
- 透明度 **23–24%**（原稿 `alphaModFix 23000/24000`）。
- **柔化边缘**（PowerPoint 原生 `a:softEdge`），不是预渲染模糊：
  - 整页截图：`rad=850900` EMU（≈89 px，原稿值）
  - 紧裁的封面片段：`rad≈285750`（≈30 px，再大就啃字）
- 图片四周不要有硬矩形边界——这是原稿的观感关键。

### 8.4 自绘示意图的语汇
- 方块：实心浅色 + 圆角，**不描边**；需要"一叠"就用三层错位 `slab()`。
- 箭头：2.6 px 灰线 + 实心小三角，不用花式箭头。
- 坐标轴：2.2 px 黑线 + 三角箭头；参考线用虚线（`8 7`），阈值线用浅红虚线（`5 6`）。
- 数据点：实心小圆 r=6–7。
- 强调窗：实心浅红块盖在网格上（如 3×3 卷积窗）。
- 禁止：阴影、3D 渐层、图标库拼贴。

### 8.5 架构图（新增页面类型）
从左到右一列方块，越走越小：`输入 → 卷积/池化 → Inception ×3 组 → 全局池化 → 全连接 → 分叉两个输出头`。
方块下方一行白话：`先看边缘、纹理 → 再组合成局部形状 → 形成整体印象 → 压成一串数字 → 分档/读数`。
面向不懂 CNN 的听众时，必须配一个"卷积窗口扫图"的小图示（9×9 亮斑网格 + 红框 + 7×7 输出）。

---

## 9. 文字密度（硬约束）

- 一页只讲一件事；讲不完就**拆页**，不要缩字号。
- 正文一行 ≤ 40 个全角字（24 px，宽 1000 px）。
- 每页正文 ≤ 3 条 / ≤ 4 行；每条 ≤ 2 行。
- 表格一律改成"字行"（≤3 行），不做真表格。
- 标题里能说清的，不要再写进正文。

---

## 10. 叙事节奏（论文汇报 12–13 页）

| # | 页面 | 作用 |
|---|---|---|
| 1 | 封面 | 英文原题 + 中文译题（关键词蓝）+ 淡化首页 |
| 2 | 这篇论文讲的什么东西？ | 一句话定位 + 论文来源（无页面标题） |
| 3 | 研究背景——为什么需要它 | 原理示意图 + 结论条 |
| 4 | 研究背景——关键概念 | 双面板示意（如 φ₂ 抖动 / 时域对比） |
| 5 | 方案架构 | 端到端流程 + 速度对比（分钟 vs 毫秒） |
| 6 | 网络结构 | 架构图（听众不懂就加"卷积窗口"图示） |
| 7 | 实验方案 | 数据怎么造、怎么考（格子图 + 三个训练集 + 未见集） |
| 8 | 关键设计 | 可解释性图（GGC/注意力）+ 一句物理判据 |
| 9–11 | 结果 I / II / III | 原图 + 2–3 个大数字，一条一条讲 |
| 12 | 评价——能/不能/我们能接 | 三列对照，落到"我们能做什么" |
| 13 | 结束 | 一句话 + 3 个讨论问题 |

原则：**先全景再细节**；每一页都能用一句话说出"这页要证明什么"。

---

## 11. 演讲备注（Notes）

- 每页 2–4 句，第一人称口语，不用书面语。
- 数字必须能复述：准确率、NRMSE、噪声档位、数据量。
- 主动写"被问到怎么答"：期刊分区、纯仿真、没做实验这类短板，写在对应页的备注里。
- 提醒自己"这条要主动讲，别等人问"的句子可以直接写在备注里。
