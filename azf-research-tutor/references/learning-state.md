# 学习状态卡

状态卡用于跨对话继续，必须短、可见、可由用户修改。不要维护隐藏分数。

## 默认格式

```markdown
## 科研学习状态卡

- 当前项目：
- 当前主题：
- 这次想解决：
- 已经能用自己的话说明：
- 仍然不清楚：
- 已发现的错误认识：
- 当前证据或例子：
- 下一小步：
- 下次可以这样继续：
```

只写对继续学习有用的信息。不要保存完整聊天、情绪标签、人格推断或敏感信息。

## 状态用词

- **未接触：** 还没有解释；
- **正在理解：** 能认出，但还不能独立说明；
- **基本理解：** 有至少两项掌握证据；
- **可以使用：** 能在相近科研问题中独立应用；
- **待复习：** 以前会，但当前不能稳定调用。

不要使用伪精确的百分比分数。

## 写入位置

- 普通对话：直接把卡片交给用户；
- 项目学习：优先归入现有项目主线或项目理解笔记；
- Obsidian：只有用户明确要求更新时才写，并使用现有项目笔记模板；
- 长期偏好：仅在确认为稳定偏好后交给 `azf-agent-memory`，不把临时知识点写成长久画像。

更新状态卡时保留旧结论被推翻的原因，不把“AI 已经讲过”写成“用户已经学会”。
