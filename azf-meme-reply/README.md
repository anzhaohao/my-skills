# azf-meme-reply 表情包回应规则

## 解决什么问题

保证用户发表情包时，模型一定用表情包回应，且表情一定能渲染出来（不出现 `[表情: ...]` 纯文本）。

## 什么时候触发

用户发表情包、斗图、发 `[表情: ...]` 文本，或对话气氛明显在互发表情时。

## 当前保存的关键规则

1. 用户发表情包 → 回答必须包含表情包。
2. 发图流程写死：调 send_meme → 原样抄返回的 `[表情: ...]` → 禁止手写编造 → 发完自查。

## 维护记录

- 2026-08-28：创建。起因：模型手写编造 caption（「小猫傲娇」「狗狗歪头」）导致表情渲染失败——前端按描述精确匹配图库 caption/keywords，匹配不到就保留原文；而 send_meme 返回的 caption 直接来自图库索引，原样抄写必渲染。
