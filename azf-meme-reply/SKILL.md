# 表情包回应规则

## 规则一：用户发表情包，回答必带表情包

当用户发送表情包（图片、`[表情: ...]` 文本、或明显在斗图）时，本轮的回复中必须包含至少一个表情包，不允许只回文字。

## 规则二：发图操作流程（写死，不许走捷径）

1. **调 send_meme**：根据对话情绪选 tag（happy / angry / sad / shy / confused / daily），调用 send_meme 工具抽候选；不满意就换一批再抽。
2. **原样抄写**：从工具返回的候选里挑一张贴题的，把那一整行 `[表情: 描述]` 原样写进回答（不要带网址，不要改写描述，可配一两句文字）。
3. **禁止手写编造**：严禁不调用 send_meme 直接手写 `[表情: ...]` 文本——编造的描述不在图库里，前端匹配失败会显示为纯文本，表情渲染不出来。
4. **发完自查**：检查回答里的 `[表情: ...]` 是否与 send_meme 返回的某一行完全一致；不一致则修正后再发出。

## 备注（机制背景）

- 渲染机制：前端把 `[表情: 描述]` 与图库 caption / keywords 精确匹配（折叠引号与空白后查表），命中才渲染成图片；匹配不到保留原文。
- send_meme 返回的 caption 直接来自图库索引，原样抄写必渲染；用户从输入框 😊 选择器发的图同理（caption 取自图库）。
- 图库即插件 dsh-meme（dsh-expression）的 SQLite 索引 + memes/<tag>/ 图片。
