这个 skill 用 Skills Manager 安装、更新、归组和部署共享技能，保留来源关联与预设信息。

# 本机约定

- 唯一中央库：`E:\software\skills-manager\skills`，这里保存真实技能文件。
- Codex、Claude Code 等客户端需要技能时，只部署指向中央库的链接。
- 新安装或接管的第三方和自建技能都加入“通用技能”预设。
- 软件界面与命令行新增技能时，本机数据库规则会自动归组；Agent 安装后仍须核对成员关系，遗漏时补加。
- 归组不等于部署；部署到哪些客户端，按用户要求决定。
- 客户端自带技能只留在各自原生目录，不加入通用预设。
- 原生技能是否通用按实际来源判断；能跨客户端运行也不能据此放进通用预设。OpenAI/Codex、Anthropic/Claude 的官方技能按本机约定排除；客户端内来源未确认的技能先不加入，确认第三方或自建后再归组。
- 更新或接管前先比较并备份，保留用户修改，不直接覆盖独立副本。
- 整理多个客户端时，先记录每个实际技能目录的名单，再逐项替换链接；保留未登记但原本就在该客户端的技能，不整组开启预设，也不把旧路径中的技能部署到另一处默认路径。
