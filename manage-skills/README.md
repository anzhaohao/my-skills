这个 skill 用 Skills Manager 安装、更新、归组和部署共享技能，保留来源关联与预设信息。

# 本机约定

- 唯一中央库：`E:\software\skills-manager\skills`，这里保存真实技能文件。
- Codex、Claude Code 等客户端需要技能时，只部署指向中央库的链接。
- 新创建、安装或接管的第三方和自建技能，都要完成 Skills Manager 登记并加入“通用技能”预设；更新已有技能时复用原记录。
- 本机数据库规则只对已新增的登记记录自动归组，不会扫描新建文件夹；Agent 收尾时仍须核对记录、可移植元数据和成员关系，遗漏时通过管理器补齐。
- 归组不等于部署；部署到哪些客户端，按用户要求决定。
- 客户端自带技能只留在各自原生目录，不加入通用预设。
- 原生技能是否通用按实际来源判断；能跨客户端运行也不能据此放进通用预设。OpenAI/Codex、Anthropic/Claude 的官方技能按本机约定排除；客户端内来源未确认的技能先不加入，确认第三方或自建后再归组。
- 更新或接管前先比较并备份，保留用户修改，不直接覆盖独立副本。
- 整理多个客户端时，先记录每个实际技能目录的名单，再逐项替换链接；保留未登记但原本就在该客户端的技能，不整组开启预设，也不把旧路径中的技能部署到另一处默认路径。

# 创建后的登记检查

先按名称、真实路径和来源查重；已有记录就复用，不为补登记而删除重装。只有文件、没有记录时，先预览单个目录，再通过管理器支持的安全导入或接管方式登记；保留整个技能目录和 supporting resources。

v1.43.4 不要把同一个中央目录盲目当作导入源和目标。已有客户端链接可以在确认真实路径相同、当前版本会保留文件后作为接管入口；不能为了登记先增加部署。没有可验证的安全入口时，明确报告“文件已创建，尚未登记”，不要手写数据库、伪造来源或覆盖原文件。

完成后检查唯一登记记录、`.skills-manager` 下的技能与预设成员元数据，以及“通用技能”成员关系。登记不改变现有客户端副本、链接和部署范围。分别报告文件、登记、预设、部署、本地提交与远端备份；不能只凭 `SKILL.md` 存在或本地提交成功就宣布完成。
